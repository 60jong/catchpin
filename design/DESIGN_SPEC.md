# catch pin — 디자인 명세 (React Native 구현용)

이 문서가 구현의 기준입니다. `screens/` 폴더의 HTML 파일은 디자인 캔버스에서 내보낸 원본 마크업으로, 정확한 좌표·크기·색을 확인할 때 참고하세요 (브라우저에서 그대로 열리지는 않을 수 있음). 화면 크기 기준은 390 × 844 (iPhone 14/15)입니다.

## 1. 디자인 토큰

### 색상
| 이름 | 값 | 용도 |
|---|---|---|
| primary | #2F6FE8 | 메인(행동): 핀, 주요 버튼, 레이더 |
| primaryDark | #1D52B8 | 버튼·핀 아래 두께면 |
| primarySoft | #E6EEFF | 선택 탭 배경 등 |
| primaryLight | #A9C4FF | 다크 배경 위 진행 링 |
| gold | #FFC21A | 보상: 포인트, 골드 핀, 광고 보상 버튼 |
| goldDark | #D99A00 | 골드 두께면 |
| onGold | #3A2A00 | 골드 위 텍스트 |
| goldText | #8A6200 | 흰 배경 위 골드 계열 텍스트 |
| ink | #1F2233 | 기본 텍스트, 내 위치 테두리 |
| muted | #5B6078 | 보조 텍스트 |
| border | #E3E7EF | 카드·입력칸 테두리 |
| surface | #F4F6FB | 입력칸·피드 배경 |
| ground | #EEF2F8 | 홈 배경 (지도 없는 버전) |
| green / greenDark | #3FBF6B / #2E9E55 | 지갑 아이콘 등 |
| infoBg / infoText | #E8F2FF / #1553B0 | 안내 칩 |
| overlayFrom / overlayTo | #1A2B5C / #0F1630 | "잡는 중" 오버레이 (방사형 그라데이션) |

색 규칙: **파랑 = 행동, 골드 = 보상.** 그라데이션은 레이더·오버레이에만 쓰고, 나머지 그림과 UI는 전부 단색 면 + 아래 두께면(플랫 스타일)입니다.

### 글꼴
- 본문·제목: **Gothic A1** (500 / 700 / 900)
- 숫자·포인트·워드마크: **Sora** (600 / 700 / 800)
- 주요 크기: 화면 제목 28–32 / 900, 시트 제목 21 / 900, 본문 15–16 / 700, 보조 13 / 700, 캡션 11–12

### 모서리·두께
- 카드: radius 20, 테두리 2px border, **아래 테두리만 4px** (눌리는 판 느낌)
- 주 버튼: 높이 54, radius 16, 배경 primary, 아래 두께 `0 4px 0 primaryDark` (그림자 번짐 없음)
- 보조 버튼: 흰 배경, 2px border 테두리, 아래 4px
- 누르면: 버튼이 두께만큼(4px) 내려가고 두께면이 사라지는 애니메이션

## 2. 공통 컴포넌트

**PinButton** (64 × 70)
- 바닥 그림자 타원 (rx 20, ry 4.5, ink 12%)
- 두께면 원 (r 26, primaryDark) — 윗면보다 6px 아래
- 윗면 원 (r 26, primary) + 좌상단 작은 흰색 하이라이트(12×6 둥근 사각형, 40%, -35° 회전)
- 가운데 "+30" (Sora 800, 17px, 흰색 / 4자리면 15px)
- 골드 변형: 윗면 gold, 두께 goldDark, 텍스트 onGold
- 터치 영역 최소 52px, 누르면 윗면이 6px 내려감
- **이름·사진 등 소유자 정보는 표시하지 않음** (익명)

**MyMarker** (56 × 56): 원형 프로필 사진, 흰 2px 안쪽 테두리 + ink 4px 바깥 테두리, 아래 `0 4px 0 #000`. 사진 없으면 회색 실루엣 기본 이미지.

**TopBar**: 좌측 포인트 카드(골드 코인 아이콘 + "12,480" Sora 800), 우측 탭권 카드(티켓 아이콘 + "3 /5" + 파란 + 버튼 → 충전 화면).

**BottomSheet** (홈): "근처에 핀 N개" / "먼저 누른 사람이 가져가요" / 우측 "오늘 획득" 골드 배지 / 실시간 피드 한 줄("누군가 방금 +40P를 가져갔어요 · 12초 전").

**TabBar** (높이 80): 지도 / 기록 / 지갑 / 내 정보. 활성 탭은 60×44 박스, primary 2px 테두리 + primarySoft 배경.

## 3. 레이더 (홈의 핵심 연출)

- 중심 = 내 위치 마커. **탐색 범위는 화면 전체** (범위 원 없음)
- 가이드 링: 반지름 96 / 192 / 288 / 384, 1px, ink 투명도 7% / 5.5% / 4% / 3%
- 스윕 빔: 원뿔형(sweep) 그라데이션, 진행 방향 뒤로 약 80° 꼬리. 투명도 0 → 2.5% → 7% → 14% → 20%(맨 앞)
- 빔 앞선: 1px, 중심에서 55% → 멀어질수록 0%
- 빔 전체에 방사형 마스크: 중심 부근 선명, 바깥으로 갈수록 사라짐
- 회전: **6초에 1바퀴, 선형, 무한 반복**
- 내 위치 빛: 지름 140 방사형 빛번짐(primary 20% → 0), 3.2초 주기로 scale 0.85 ↔ 1.1
- 핀 감지 반응: 빔이 핀 각도를 지나는 순간 핀 둘레 링이 r 27 → 42로 퍼지며 사라짐 (약 0.9초, 1.5px, 50% → 0). 골드 핀은 골드 링
- 권장 구현: `@shopify/react-native-skia` (SweepGradient + 회전) + `react-native-reanimated`
- 기기 '동작 줄이기' 설정 시 애니메이션 정지

## 4. 화면과 흐름

```
로그인 ─┬─ 카카오 / Apple / Google ──────────────→ 홈
        └─ 이메일로 로그인 → 이메일 로그인 ──────→ 홈
홈 ─┬─ 핀 탭 → [잡는 중 오버레이] → 획득 or 한 발 늦음 → 홈
    └─ 탭권 + → 탭권 충전 → 홈
```

**로그인** (Login.dc.html): 상단 앱 아이콘 + 워드마크 + "내 주변 핀을 가장 먼저 눌러 포인트를 모아보세요". 버튼 순서: 카카오(#FEE500) → Apple(검정) → Google(흰색). "또는" 구분선 아래 "이메일로 로그인" 텍스트 버튼. 하단 약관 문구(이용약관, 개인정보처리방침, 위치기반서비스 이용약관). 로고 자리는 각 사 공식 로고 에셋 사용.

**이메일 로그인** (LoginEmail.dc.html): 이메일 / 비밀번호(보기 토글) / 비밀번호 찾기 / 로그인 버튼 / 회원가입 링크.

**홈** (MainLite.dc.html가 기본, Main.dc.html은 지도 레이어 추가 버전): 배경 ground 단색 + 레이더 + 랜덤 위치 핀 + 내 마커 + TopBar + BottomSheet + TabBar. 핀이 겹치면 서로 밀어내기.

**잡는 중 오버레이** (Won/Lost 화면 위에 덮임, 결과와 무관하게 동일)
| 시간 | 동작 |
|---|---|
| 0 – 0.5s | 탭한 핀이 화면 중앙에 scale 0.35 → 1.08 → 1 |
| 0.5 – 0.8s | 핀 윗면이 9px 눌렸다 복귀 |
| 0.65 – 1.75s | 핀 둘레 진행 링(r 86, 4px, primaryLight) 시계방향으로 채워짐 |
| 2.25 – 2.6s | 오버레이 페이드아웃 |
| 2.3 – 2.75s | 결과 내용이 16px 아래에서 올라오며 나타남 |
실제 앱: 오버레이는 **서버 판정 도착 + 최소 1.5초** 중 늦은 쪽까지 유지. 텍스트 "잡는 중 / 누가 먼저 눌렀는지 확인하고 있어요". 결과를 암시하는 표시 금지.

**획득** (Won.dc.html): 흰 배경, 골드 햇살 + 체크 찍힌 큰 핀 + 색종이, "먼저 잡았어요!", "120m 거리의 핀을 가져왔어요", 타일 2개(획득 포인트 / 반응 속도), 골드 버튼 "광고 보고 2배로 받기", 보조 버튼 "계속하기".

**한 발 늦음** (Lost.dc.html): 스톱워치 그림, "앗, 한 발 늦었어요", "다른 헌터가 0.3초 먼저 눌렀어요", 비교 카드(다른 헌터 / 나, 시각, 포인트), 안내 칩 "탭권은 돌려드렸어요 · 3/5", 버튼 "다음 핀 찾기".

**탭권 충전** (Refill.dc.html): 티켓 그림, "탭권을 다 썼어요", 보유 탭권 카드(0/5 빈 슬롯 5칸, 무료 충전 타이머 "1시간마다 1장"), 광고 1편 → +1, 광고 3편 연속 → +4(보너스 배지), 하단 "오늘 광고 충전 N회 남음".

**로고** (Brand.dc.html): 파란 둥근 사각형 + 흰 C 곡선 + 가운데 금빛 점. 워드마크 "catch pin"은 i의 점이 금빛 점.

## 5. 제품 규칙
- 탭권 최대 5장, 1시간마다 1장 무료 충전, 광고로 충전(일일 한도)
- 선점당하면 탭권 환불
- 핀 위치는 랜덤, 소유자 익명
- **먼저 누른 사람 판정은 반드시 서버에서** (원자적 조건부 업데이트, 서버 시각 기준)
- 광고 보상은 AdMob 서버 측 확인(SSV) 후 지급
